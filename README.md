<h2 id="-兼容性与依赖" align="center">
<img src="https://media.giphy.com/media/jSKBmKkvo2dPQQtsR1/giphy.gif" width="25px" height="25px" style="vertical-align: middle; position: relative; top: -2px;"/>
兼容性与依赖
</h2>

> 官方上游并未发布 26.2 版本（其 `master` 仍停在 26.1.2）。本仓库基于上游的 26.2 移植分支（[MOPELotus/ModernUI-MC](https://github.com/MOPELotus/ModernUI-MC) 分支 `26.2`）构建，并额外修复了若干问题、重做了操作中心的公告栏。

| 项目 | 要求 | 本包实测 |
|---|---|---|
| **Minecraft** | **26.2**（jar 内声明 `>=26.2 <26.3`，26.2.x 均可） | 26.2 ✅ |
| **加载器** | **仅 Fabric**（本 Release 为 Fabric 构建） | Fabric ✅ |
| **Fabric Loader** | **≥ 0.19.3** | 0.20.0 ✅ |
| **Fabric API** | **≥ 0.153.0+26.2**（建议用最新，如 `0.161.0+26.2`） | 0.161.0+26.2 ✅ |
| **Java** | **25**（Minecraft 26.x 强制） | Microsoft OpenJDK 25.0.3 ✅ |
| **其它前置 Mod** | **无**。本移植版用内置 `SimpleConfigSpec` 取代了 Forge Config API Port，**不需要任何额外依赖** | — |
| **运行侧** | 客户端专用（`environment: client`），**不要装到服务端** | — |
| **渲染后端** | **OpenGL 已实机验证**；Minecraft 26.x 的原生 **Vulkan 路径尚未在 26.2 实机验证** | OpenGL / NVIDIA 616.92 ✅ |
| **已知冲突** | jar 内声明与 `blur`、`tipthescales` 冲突；`Remove Reloading Screen` 若 `hideOverlays = "ALL"` 可能崩溃 | 规避：把它改成 `"RELOADING"` |

**与上游 Forge / NeoForge 包的差异**：上游 Forge / NeoForge 构建带有 `C` 缩放键与 Forge Config API Port 依赖；**本 Fabric 包没有缩放键，也不需要任何额外依赖**。

**避免踩坑**：只放一个 ModernUI jar（mod id 都是 `modernui`，不能与官方 26.1.2 的包共存）。

<h2 id="-本修改版改了什么" align="center">
<img src="https://media.giphy.com/media/Sqlj82Xy4eZKSU9iVM/giphy.gif" width="30px" height="30px" style="vertical-align: middle; position: relative; top: -2px;"/>
本修改版改了什么
</h2>

### 🗂️ 配置读写（`SimpleConfigSpec`）

| 问题 | 修复 |
|---|---|
| 每个 section 首个键的注释被写入两次 | 去掉重复输出 |
| `NaN` / `Infinity` 被当作有效数值 | 非有限值回落默认值 |
| 字符串值不转义换行 / 制表 / 控制字符 | 完整转义与解码（`\n \r \t \b \f \" \\ \uXXXX`） |
| 不支持 TOML 单引号字面量，值内 `#` 被截断 | 同时支持 `"…"` 与 `'…'` |
| 无 section 时写出非法空表头 `[]` | 空 section 不写表头 |

### 🛡️ 稳定性

| 问题 | 修复 |
|---|---|
| 配置目录不可写会中断游戏启动 | 改为告警并回退内存默认值 |
| 文本采样在坐标重写前判定，可能残留抖动 | 判定改用实际绘制原点 |
| `NativeVulkanIntegration` 字段解析失败即类加载期硬崩 | 改为惰性解析 + 可诊断异常（`NativeVulkanIntegration$Offsets`） |
| Vulkan 物理设备特性结构重复分配 | 按设备复用（并注明为何不提前释放） |
| 依赖下限声明过松（`>=0.15.0` / `>=0.90.7`） | 改为与编译目标一致（`>=0.19.3` / `>=0.153.0`） |

### 📢 操作中心「公告栏」

| 问题 | 修复 |
|---|---|
| 主页写死 `Modern UI 3.13.0` 并列出上游 3.13.0 的卖点 | 改为运行时读取版本，显示修改人 / 原作者 / 官方仓库 / 本修改版仓库与下载地址 |
| 更新日志从 `raw.githubusercontent.com` 联网拉取（国内常超时，内容还是上游的） | 改为读取 jar 内置公告（`assets/modernui/changelogs.md`），离线可用 |
| 下载链接指向官方 CurseForge / Modrinth（本移植版并未发布在那里） | 改为指向本仓库 Releases |

> 除公告栏外，操作中心其余页面（偏好设置、高级选项、音乐页等）与上游保持一致，**未作改动**。

<h2 id="-从源码构建" align="center">
<img src="https://media.giphy.com/media/jSKBmKkvo2dPQQtsR1/giphy.gif" width="25px" height="25px" style="vertical-align: middle; position: relative; top: -2px;"/>
从源码构建
</h2>

需要 **JDK 25**：

```sh
./gradlew :ModernUI-Fabric:build     # 只构建 Fabric
./gradlew build                       # 构建 Fabric / Forge / NeoForge
```

产物位于 `fabric/build/libs/`。默认构建普通版；MiSans 版使用 `-Pfont_variant=misans`。
